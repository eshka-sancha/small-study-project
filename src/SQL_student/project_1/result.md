#Отчет по проекту

##О чем проект и в чем его цель

Это учебный проект, сделанный в формате лабораторной работы по курсу "Базы данных". 
Целью проекта я поставила демонстрацию навыков написания простых запросов с использованием операций UNION, UNION ALL, INTERSECT, EXCEPT, JOIN, а также запросов 
с использованием сортировки и агрегационных запросов ORDER BY, GROUP BY, работа с нормализацией.
Задача проекта состояла в создании базы данных, имитирующей работу сервиса для совершения онлайн покупок.

##Структура базы данных

1. Таблица client содержит данные о клиентах - айди, имя, адрес, дата рождения
2. Таблица item содержит данные о товарах в магазине - айди, наименование, описание
3. Таблица buy создана для объединения данных из двух предыдущих таблиц. Содержит айди покупателя и товара.

#Схема базы данных

Между таблицами есть связи

   1. между таблицами client и buy связь "один ко многим" так как один клиент может купить много товаров
   2. между таблицами "item" и "buy" связь "один ко многим" так как один товар может быть куплен много раз
